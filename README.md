# Flux — Music for your personal Google Drive

By Rein. Windows x64.

## Download

**[Install Flux with automatic updates](https://github.com/morinjin05/flux-downloads/releases/latest)** — choose `Flux-Setup-0.5.2-Windows.exe`.

Close any older Flux window before installation. Install once; future stable updates download in the background. In Settings, choose **Cập nhật và khởi động lại** when ready. Flux checks after launch and every six hours. Playback is not interrupted automatically.

Existing portable 0.5.1 users must download this installer once to enable auto-update. The portable download remains available for users who prefer manual updates.

Connect your own Google account to use your own Drive. Updates preserve Flux user data and do not delete your cloud library. Link imports can use temporary disk space; Google quota and source restrictions still apply.

The application is currently unsigned. Download only from this repository and compare SHA-256 with `SHA256SUMS.txt` in the release.

Editable Flux source is maintained in a separate private repository. This repository contains download information and third-party notices only. Code protection cannot prevent all reverse engineering. Third-party components retain their own licenses; see the notices supplied here.
