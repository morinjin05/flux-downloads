# Flux 0.5.1 for Windows

Portable Windows x64 application. Extract this package and open Flux-Desktop-0.5.1-Windows.exe.
Close any older Flux instance before starting this version.

Connect your own Google account to use your personal Drive. Music imported from links
may use temporary disk space until upload completes; Google quota and source restrictions apply.

This download package contains the application and notices, not the editable Flux source project.
The executable is not digitally signed. Compare its SHA-256 with SHA256SUMS.txt after downloading.
Code protection makes inspection harder; it does not make reverse engineering impossible.

Third-party components retain their respective licenses in THIRD-PARTY-NOTICES.txt.
Download the latest Windows app from https://github.com/morinjin05/flux-downloads/releases/latest .
